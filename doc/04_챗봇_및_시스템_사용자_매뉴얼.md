# StuEdit 챗봇 및 전체 시스템 사용자 매뉴얼

## 1. 시스템 시작 및 로그인

### 1.1 접속

1. 브라우저(Chrome, Edge 권장)를 열고 시스템 URL 입력
2. 로그인 화면이 표시됩니다

### 1.2 로그인

1. **아이디**: 발급받은 로그인 아이디 입력
2. **비밀번호**: 초기 비밀번호 입력
3. **로그인** 버튼 클릭

| 구분 | 기본 아이디 | 기본 비밀번호 |
|------|------------|--------------|
| 관리자 | admin | admin1234 |
| 학생(예시) | student01 | student1234 |

> 처음 로그인 후 반드시 비밀번호를 변경하세요.

### 1.3 로그아웃

- 우측 상단 사용자명 클릭 → **로그아웃** 선택
- 30분 이상 미사용 시 자동 로그아웃

## 2. 대시보드

로그인 후 표시되는 메인 화면입니다.

### 2.1 관리자 대시보드

| 위젯 | 내용 |
|------|------|
| 전체 학생 수 | 등록된 재적 학생 총 수 |
| 이번 달 신규 | 당월 신규 등록 학생 수 |
| 오늘 출석률 | 당일 출결 등록 기준 출석률(%) |
| 공지사항 수 | 전체 공지 게시물 수 |
| 학과별 학생 분포 | 학과별 학생 수 차트 |
| 최근 등록 학생 | 최근 5명 학생 목록 |

### 2.2 학생 대시보드

- 본인 성적 요약 (GPA, 평균 점수)
- 본인 출석률
- 최근 공지사항
- 다가오는 학사 일정

## 3. 학생 관리 (관리자 전용)

### 3.1 학생 목록 조회

**메뉴:** 학생 관리 → 학생 목록  
**URL:** `/student/list.do`

- 학번, 이름, 학과, 학년별 검색 가능
- 10건씩 페이지 단위 표시
- **Excel 다운로드**: 전체 학생 목록을 엑셀 파일로 저장

### 3.2 학생 등록

1. [학생 등록] 버튼 클릭
2. 필수 항목 입력:
   - 학번 (중복 불가), 이름, 학과, 학년
3. 선택 항목: 연락처, 이메일, 주소, 성별, 생년월일
4. [저장] 클릭
5. 이메일 주소 입력 시 환영 메일 자동 발송

### 3.3 학생 정보 수정

1. 학생 목록에서 대상 학생 클릭 → 상세 보기
2. [수정] 버튼 클릭
3. 내용 변경 후 [저장]

### 3.4 학생 삭제

1. 학생 상세 화면에서 [삭제] 버튼 클릭
2. 확인 팝업에서 [확인] 클릭
3. 논리 삭제 처리 (목록에서 미표시, DB 보존)

## 4. 성적 관리

### 4.1 성적 조회 (관리자)

**메뉴:** 성적 관리 → 성적 목록  
- 학번/이름/학기 검색 가능
- 학생별 GPA 및 평균 점수 확인

### 4.2 성적 조회 (학생)

**메뉴:** 내 성적  
- 본인 성적만 조회
- 학기 선택 후 해당 학기 성적/GPA 확인

### 4.3 성적 입력 (관리자)

1. [성적 입력] 버튼 클릭
2. 학생 선택 → 학기, 과목명, 점수, 등급, 학점 입력
3. [저장] — 중복 입력 시 오류 메시지 표시

### 4.4 성적 수정/삭제 (관리자)

- 목록에서 해당 성적 행 클릭 → [수정] 또는 [삭제]

---

## 5. 출결 관리

### 5.1 출결 조회 (관리자)

**메뉴:** 출결 관리 → 출결 목록  
- 학번/이름/기간/상태로 검색
- 학생별 출석률 통계 표시

### 5.2 출결 조회 (학생)

**메뉴:** 내 출결  
- 기간 선택 후 본인 출결 현황 확인
- 출석/지각/결석/공결 횟수 및 출석률 표시

### 5.3 출결 등록 (관리자)

1. [출결 등록] 버튼 클릭
2. 학생 선택 → 날짜, 출결 상태, 비고(공결 사유 등) 입력
3. [저장] — 동일 날짜 중복 시 오류 메시지 표시

### 5.4 출결 상태 설명

| 상태 | 출석률 반영 |
|------|:----------:|
| 출석 | O |
| 지각 | X |
| 결석 | X |
| 공결 | O (인정 결석) |

## 6. 공지사항

### 6.1 공지 목록 조회

**메뉴:** 공지사항  
- 중요 공지는 상단 고정 표시
- 제목 클릭 시 상세 내용 확인
- 조회 시 조회수 자동 증가

### 6.2 공지 작성 (관리자)

1. [공지 작성] 버튼 클릭
2. 제목, 내용 입력
3. 중요 공지 설정 (체크 시 상단 고정)
4. 첨부파일 추가 (선택, 최대 10MB)
5. [저장]

### 6.3 첨부파일 다운로드

- 공지 상세에서 첨부파일 목록 확인
- 파일명 클릭 시 다운로드

### 6.4 공지 수정/삭제 (관리자)

- 공지 상세에서 [수정] 또는 [삭제] 버튼 클릭

## 7. 1:1 문의

### 7.1 문의 목록 조회

**메뉴:** 1:1 문의  
- 관리자: 전체 문의 조회
- 학생: 본인 문의만 조회
- 상태별 필터: 대기 / 답변완료

### 7.2 문의 작성 (학생/관리자)

1. [문의 작성] 버튼 클릭
2. 제목, 내용 입력
3. **비밀글** 설정 가능 (본인과 관리자만 열람)
4. [저장]

### 7.3 답변 등록 (관리자)

1. 문의 상세 화면에서 답변 입력란 확인
2. 답변 내용 작성 후 [답변 등록] 클릭
3. 문의 상태 자동으로 '답변완료' 변경

## 8. 설문조사

### 8.1 설문 목록 조회

**메뉴:** 설문조사  
- 진행 중 / 종료 설문 구분 표시
- 이미 참여한 설문은 '참여완료' 표시

### 8.2 설문 참여 (학생/관리자)

1. 진행 중인 설문 클릭
2. 각 질문에 응답 (단일 선택, 복수 선택, 텍스트)
3. [제출] 클릭
4. 동일 설문 중복 참여 불가

### 8.3 설문 결과 조회 (관리자)

1. 설문 목록에서 [결과 보기] 클릭
2. 질문별 응답 현황, 선택지별 응답 수/비율 확인

### 8.4 설문 생성 (관리자)

1. [설문 생성] 버튼 클릭
2. 설문 제목, 설명, 시작일, 종료일 설정
3. 질문 추가: 단일 선택 / 복수 선택 / 주관식
4. 선택형 질문에 선택지 항목 추가
5. [저장]

## 10. AI 챗봇 사용 방법

### 10.1 챗봇 접속

**메뉴:** AI 챗봇 (사이드바 하단)  
**URL:** `/chatbot/chat.do`  
**권한:** 전체 로그인 사용자

### 10.2 챗봇 기능 소개

StuEdit AI 챗봇은 **Google Gemini 2.5 Flash** 기반의 AI 어시스턴트입니다.  
학생의 학업 정보(성적, 출결)를 기반으로 개인화된 상담을 제공합니다.

### 10.3 챗봇 사용법

1. 화면 하단 메시지 입력창에 질문 입력
2. **Enter** 또는 **전송** 버튼 클릭
3. AI 응답 대기 (로딩 애니메이션 표시)
4. 응답 확인

### 10.4 빠른 질문 버튼

화면에 미리 준비된 자주 묻는 질문 버튼:

| 버튼 | 설명 |
|------|------|
| 성적 분석 | 현재 성적 상태 분석 및 개선 방향 |
| 출결 현황 확인 | 출석률 및 출결 위험도 확인 |
| GPA 계산 방법 | GPA 산출 방식 안내 |
| 학점 이수 조건 | 졸업 요건 관련 안내 |

### 10.5 챗봇 활용 예시

**성적 관련:**
```
사용자: 내 GPA가 얼마야?
챗봇: 현재 누적 GPA는 3.45입니다. 이번 학기에 등록된 과목은
      자료구조(A+), 알고리즘(B+), 데이터베이스(A)로...
```

**출결 관련:**
```
사용자: 나 출석률 괜찮아?
챗봇: 현재 출석률은 82.5%입니다. 출석 17회, 지각 2회, 결석 1회로
      정상 범위에 있습니다. 다만 결석이 더 늘어나면...
```

**학업 상담:**
```
사용자: 성적 올리는 방법 알려줘
챗봇: 현재 가장 낮은 점수 과목은 알고리즘(72점)입니다.
      해당 과목 집중 학습을 권장하며...
```

### 10.6 챗봇 이용 시 주의사항

| 항목 | 내용 |
|------|------|
| 응답 시간 | 일반적으로 3~10초 소요 |
| 서비스 장애 | Google 서버 과부하 시 자동 재시도 (최대 3회) |
| 재시도 대기 | 1차 실패: 2초, 2차 실패: 4초 후 재시도 |
| 최종 실패 시 | "잠시 후 다시 시도해 주세요" 메시지 표시 |
| 대화 기록 | 이전 대화 내용이 화면에 유지됨 (최근 20건) |
| 개인 정보 | 본인 성적/출결 정보만 AI에 제공 |

### 10.7 챗봇이 제공하는 정보

- 본인 성적 데이터 (최근 10개 과목)
- 본인 출결 통계 (총 횟수, 출석/지각/결석/공결 수, 출석률)
- 일반 학업 조언 및 안내

### 10.8 챗봇으로 할 수 없는 것

- 성적/출결 **수정** 또는 **등록** 요청
- 다른 학생의 정보 조회
- 행정 처리 신청 (등록금, 장학금 등)

## 12. 자주 묻는 질문 (FAQ)

**Q. 비밀번호를 잊어버렸어요.**  
A. 관리자에게 문의하면 비밀번호를 초기화해 드립니다. DB에서 BCrypt 암호화된 값을 교체합니다.

**Q. 로그인이 안 됩니다.**  
A. 대소문자 구분 확인, Caps Lock 확인 후 재시도. 계속 안 되면 관리자에게 계정 상태 확인 요청.

**Q. 챗봇이 응답하지 않아요.**  
A. 잠시 후 재시도해 주세요. Google Gemini 서버의 일시적 과부하일 수 있습니다 (자동 재시도 처리됨).

**Q. 성적/출결 오류가 있어요.**  
A. 학생은 1:1 문의를 통해 수정 요청. 관리자는 직접 수정 가능.

**Q. 파일 첨부가 안 됩니다.**  
A. 파일 크기 10MB 이하 확인. 업로드 가능한 파일 형식 확인.

**Q. 설문에 중복 참여하고 싶어요.**  
A. 1인 1회 참여만 가능하며, 제출 후 수정/재제출 불가합니다.

## 13. 문의 및 지원

시스템 이용 중 문제가 발생하면:

1. **1:1 문의** 메뉴를 통해 관리자에게 문의
2. 긴급 문제는 관리자에게 직접 연락

| 유형 | 처리 담당 | 예상 처리 시간 |
|------|----------|--------------|
| 로그인 오류 | 관리자 | 즉시 |
| 성적/출결 오류 | 관리자 | 1 영업일 |
| 시스템 오류 | 개발팀 | 1~3 영업일 |
| 챗봇 오류 | 자동 재시도 / 개발팀 | 자동 또는 1 영업일 |
