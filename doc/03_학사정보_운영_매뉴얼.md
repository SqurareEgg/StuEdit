# StuEdit 학사 정보(성적/출결) 운영 매뉴얼

## 1. 개요

학사 정보 관리 시스템은 학생별 **성적**과 **출결**을 등록·수정·조회·삭제하는 기능을 제공합니다.
관리자만 데이터 입력/수정/삭제가 가능하며, 학생은 본인 정보만 조회할 수 있습니다.

---

## 2. 성적 관리

### 2.1 성적 목록 조회

**URL:** `/grade/list.do`  
**권한:** ROLE_ADMIN, ROLE_STUDENT (학생은 본인 성적만)

#### 조회 화면 구성

| 항목 | 설명 |
|------|------|
| 검색 조건 | 학번, 이름, 학과, 학기 필터 |
| 목록 컬럼 | 학번, 이름, 과목명, 학기, 점수, 등급, 학점, 등록일 |
| 페이지 단위 | 10건씩 표시 (하단 페이징) |

#### 학기 형식

```
형식: YYYY-N  (예: 2024-1, 2024-2)
1학기: 3월 ~ 8월
2학기: 9월 ~ 2월
```

### 2.2 성적 등록

**URL:** `/grade/insertForm.do` → POST `/grade/insert.do`  
**권한:** ROLE_ADMIN

#### 입력 항목

| 항목 | 필수 | 형식 | 설명 |
|------|:----:|------|------|
| 학생 선택 | O | 목록 선택 | 학번+이름으로 선택 |
| 과목명 | O | 텍스트 | 최대 100자 |
| 학기 | O | YYYY-N | 드롭다운 선택 |
| 점수 | O | 소수점 2자리 | 0.00 ~ 100.00 |
| 등급 | O | 드롭다운 | A+, A, B+, B, C+, C, D+, D, F |
| 학점 | O | 정수 | 1 ~ 6 |

#### 등급-점수 기준표

| 점수 범위 | 등급 | 등급점수 |
|-----------|------|----------|
| 90점 이상 | A+ | 4.5 |
| 85 ~ 89 | A | 4.0 |
| 80 ~ 84 | B+ | 3.5 |
| 75 ~ 79 | B | 3.0 |
| 70 ~ 74 | C+ | 2.5 |
| 65 ~ 69 | C | 2.0 |
| 60 ~ 64 | D+ | 1.5 |
| 55 ~ 59 | D | 1.0 |
| 55 미만 | F | 0.0 |

#### 중복 등록 방지

동일 학생의 동일 학기 + 동일 과목명은 **중복 입력 불가**합니다.  
시도 시 오류 메시지: `"이미 등록된 성적입니다. (동일 학기, 동일 과목)"`

### 2.3 성적 수정

**URL:** `/grade/updateForm.do?gradeId={id}` → POST `/grade/update.do`  
**권한:** ROLE_ADMIN

- 모든 항목 수정 가능 (과목명, 학기, 점수, 등급, 학점)
- 수정 후 중복 여부 재검증 (자기 자신 제외)

### 2.4 성적 삭제

**URL:** POST `/grade/delete.do`  
**권한:** ROLE_ADMIN

- 논리 삭제 방식 (`del_yn = 'Y'`)
- 삭제 후 목록에서 미표시
- 삭제된 데이터는 DB에 보존 (감사 추적 가능)

### 2.5 GPA(학점 평균) 계산

학생 성적 상세 조회 시 자동 계산됩니다.

**계산 공식:**
```
GPA = Σ(각 과목 등급점수 × 학점) / Σ(전체 학점)
평균 점수 = Σ(점수) / 과목 수
```

**예시:**
| 과목 | 점수 | 등급점수 | 학점 |
|------|------|----------|------|
| 자료구조 | 92 | 4.5 | 3 |
| 알고리즘 | 78 | 3.0 | 3 |
| 데이터베이스 | 85 | 4.0 | 3 |
| **합계** | | **Σ(등급점수×학점)=34.5** | **9** |

```
GPA = 34.5 / 9 = 3.83
평균 점수 = (92+78+85) / 3 = 85.0
```

### 2.6 학기별 성적 조회 (학생용)

학생은 학기를 선택해 해당 학기의 성적 목록과 GPA를 확인합니다.

1. 로그인 후 [성적 조회] 메뉴 클릭
2. 학기 드롭다운에서 원하는 학기 선택
3. 과목별 점수, 등급, 학점, GPA 확인

## 3. 출결 관리

### 3.1 출결 목록 조회

**URL:** `/attend/list.do`  
**권한:** ROLE_ADMIN, ROLE_STUDENT (학생은 본인만)

#### 조회 화면 구성

| 항목 | 설명 |
|------|------|
| 검색 조건 | 학번, 이름, 기간(시작일~종료일), 출결 상태 |
| 목록 컬럼 | 학번, 이름, 날짜, 상태, 비고, 등록일 |
| 통계 표시 | 총 횟수, 출석, 지각, 결석, 공결, 출석률 |
| 페이지 단위 | 10건씩 (하단 페이징) |

### 3.2 출결 상태 정의

| 상태 | 설명 | 출석률 반영 |
|------|------|:----------:|
| 출석 | 정상 출석 | O (출석으로 계산) |
| 지각 | 지각 출석 | X (결석으로 계산) |
| 결석 | 무단 결석 | X |
| 공결 | 공식 인정 결석 (병결, 경조사 등) | O (출석으로 계산) |

**출석률 공식:**
```
출석률(%) = (출석 + 공결) / 전체 출결 횟수 × 100
```

### 3.3 출결 등록

**URL:** `/attend/insertForm.do` → POST `/attend/insert.do`  
**권한:** ROLE_ADMIN

#### 입력 항목

| 항목 | 필수 | 형식 | 설명 |
|------|:----:|------|------|
| 학생 선택 | O | 목록 선택 | 학번+이름으로 선택 |
| 출결 일자 | O | YYYY-MM-DD | 날짜 선택기 |
| 출결 상태 | O | 드롭다운 | 출석/지각/결석/공결 |
| 비고 | X | 텍스트 | 최대 200자 (공결 사유 등) |

#### 중복 등록 방지

동일 학생 + 동일 날짜는 **중복 입력 불가**합니다.  
오류 메시지: `"해당 날짜에 이미 출결 정보가 존재합니다."`

### 3.4 출결 수정

**URL:** `/attend/updateForm.do?attendId={id}` → POST `/attend/update.do`  
**권한:** ROLE_ADMIN

- 출결 상태, 비고 수정 가능
- 학생 및 날짜는 수정 불가 (삭제 후 재등록 방식)

### 3.5 출결 삭제

**URL:** POST `/attend/delete.do`  
**권한:** ROLE_ADMIN

- 논리 삭제 방식 (`del_yn = 'Y'`)

### 3.6 출결 통계 확인

**대시보드 (관리자):**
- 오늘 출석률: 당일 출결 등록 기준 실시간 계산
- 전체 학생 출석 현황 요약

**학생별 상세 통계:**
```
총 횟수: N회
출석: N회 / 지각: N회 / 결석: N회 / 공결: N회
출석률: N.N%
```

**출석 위험 판단 기준 (AI 챗봇 연동):**
| 출석률 | 상태 |
|--------|------|
| 80% 이상 | 정상 |
| 70% ~ 79% | 주의 |
| 70% 미만 | 위험 (수업 실격 가능) |

### 3.7 일괄 출결 등록 운영 방법

현재 시스템은 1건씩 등록 방식입니다. 대량 등록이 필요한 경우:

**방법 1: DB 직접 INSERT (관리자)**
```sql
INSERT INTO TB_ATTEND (student_id, attend_date, attend_status, note)
VALUES 
  ((SELECT student_id FROM TB_STUDENT WHERE student_num='2024001'), '2024-09-02', '출석', ''),
  ((SELECT student_id FROM TB_STUDENT WHERE student_num='2024002'), '2024-09-02', '출석', '');
```

**방법 2: Excel 업로드 기능 (향후 개발 예정)**
- 엑셀 양식 다운로드 → 데이터 입력 → 업로드

## 4. 학사 일정 관리

### 4.1 학사 일정 조회

**URL:** `/schedule/list.do`  
**권한:** 전체 로그인 사용자

- 일정 목록을 시작일 기준 정렬 조회
- 일정 유형별 색상 구분 표시

### 4.2 학사 일정 유형

| 유형 | 설명 | 표시 색상 |
|------|------|----------|
| 일반 | 일반 학사 일정 | 기본 |
| 시험 | 중간/기말 시험 | 빨강 |
| 방학 | 방학 기간 | 초록 |
| 휴일 | 공휴일, 학교 공휴일 | 회색 |

### 4.3 학사 일정 등록/수정/삭제

**권한:** ROLE_ADMIN

| 항목 | 필수 | 설명 |
|------|:----:|------|
| 일정명 | O | 최대 200자 |
| 내용 | X | 상세 설명 |
| 시작일 | O | YYYY-MM-DD |
| 종료일 | O | YYYY-MM-DD (시작일 이후) |
| 유형 | O | 일반/시험/방학/휴일 |

## 5. 주요 운영 시나리오

### 시나리오 1: 학기 성적 일괄 등록

1. 성적 입력 대상 학생 목록 확인 (`/student/list.do`)
2. 각 학생의 성적 입력 (`/grade/insertForm.do`)
3. 학기, 과목명, 점수, 등급, 학점 입력 후 저장
4. 전체 성적 조회로 입력 완료 확인 (`/grade/list.do?semester=2024-1`)

### 시나리오 2: 결석 처리 및 공결 전환

1. 결석 처리: 출결 등록 시 상태 = '결석', 비고에 사유 입력
2. 공결 신청 후 승인 시: 해당 출결 수정 → 상태 = '공결', 비고에 승인 내용 입력
3. 학생의 출석률 자동 재계산 확인

### 시나리오 3: 학기 초 학사 일정 등록

1. 학사 일정 등록 메뉴 접속 (`/schedule/insertForm.do`)
2. 개강일, 중간고사 기간, 기말고사 기간, 방학 기간 순서로 등록
3. 학생들이 학사 캘린더에서 일정 확인 가능

### 시나리오 4: 출석률 저조 학생 파악

1. 출결 목록에서 기간 설정 후 전체 조회
2. 학생별 출석률 통계 확인
3. 70% 미만 학생에게 별도 안내 필요

## 6. 데이터 관리 주의사항

| 항목 | 주의사항 |
|------|----------|
| 삭제 후 복구 | 논리 삭제이므로 DB에서 `del_yn='N'` 으로 직접 복구 가능 |
| 중복 등록 | 시스템 차원 방지 — 동일 학기+과목, 동일 날짜 차단 |
| 성적 확정 | 학생에게 공개 전 입력 오류 재확인 필요 (수정 가능하지만 이력 관리 미지원) |
| 출결 소급 | 과거 날짜 출결 등록 가능 — 날짜 오입력 주의 |
| 백업 | 성적/출결 데이터는 정기 DB 백업 필수 (주 1회 이상 권장) |
